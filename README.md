# SER Teacher | خدمات معلمين

منصة عربية مستقلة لإدارة بيانات المعلم والصفوف والمواد، وإنشاء دفتر العلامات ودفتر الحضور والغياب مع طباعة A4 رسمية.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env.local` وأضف بيانات Neon وResend.
2. ثبّت الحزم: `npm install`
3. طبّق قاعدة البيانات: `npm run db:migrate`
4. شغّل الموقع: `npm run dev`

## النشر

المشروع جاهز للنشر على Vercel. أضف متغيرات البيئة نفسها في إعدادات المشروع، ثم نفّذ ترحيل قاعدة البيانات مرة واحدة.
