# SER Teacher | خدمات معلمين

منصة عربية مستقلة لإدارة بيانات المعلم والصفوف والمواد، وإدخال علامات دفتر العلامات إلكترونيًا لكل صف ومادة وفصل دراسي، مع تجهيز دفاتر العلامات والحضور والغياب للطباعة على A4.

## الصفحات

- `/setup` — بيانات المدرسة والصفوف والمواد وربطها، مع تعديل اسم المادة وحذفها وفك ربطها عن صف.
- `/marks` — إدخال العلامات لكل صف ومادة. خمسة أقسام (اختبار قصير 1، نصف الفصل، قصير 2، التقويم النوعي، نهاية الفصل) لكل فصل دراسي، والمجموع يُحسب تلقائيًا من 100. علامة الإكمال متاحة في الفصل الثاني فقط.
- `/gradebooks` — تجهيز صفحات الطباعة؛ العلامات المُدخلة تظهر جاهزة في الجداول المطبوعة.


## التشغيل المحلي

1. انسخ `.env.example` إلى `.env.local` وأضف اتصال Supabase ومفتاحه القابل للنشر.
2. ثبّت الحزم: `npm install`
3. طبّق قاعدة البيانات: `npm run db:migrate`
4. شغّل الموقع: `npm run dev`

## النشر

المشروع جاهز للنشر على Vercel، وقاعدته المستقلة على Supabase PostgreSQL. أضف متغيرات البيئة نفسها في إعدادات المشروع؛ ترحيلات قاعدة البيانات محفوظة داخل `db/migrations`.
